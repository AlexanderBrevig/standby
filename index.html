Standby

IPSC range commands, a random start beep and a shot timer that listens for your shots.

  • Uses the microphone for shots and voice commands. Works best in Chrome on Android.
  • Say “restart” to run a string, “not ready” after “Are you ready?” to hold.
  • Treat every gun as loaded.

setup …While idle: change the drill, e.g. “setup draw drill from table, five reps, par adaptive”, “setup called, my targets five paper three steel”. Then “confirm” or “cancel”. Add “and go” to start at once.
setup?Read back the current setup (also “what’s set”)
setup undoUndo the last setup change
